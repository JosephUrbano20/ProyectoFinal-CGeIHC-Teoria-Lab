
# Museo Interactivo en OpenGL

Proyecto final de la materia de Computación Gráfica e Interacción
Humano-Computadora.

## Descripción

Desarrollamos un museo virtual utilizando
C++ y OpenGL, con exhibiciones relacionadas con la
cultura mexicana.

El proyecto incluye modelos tridimensionales,
texturas, iluminación, cámara libre y animaciones.

## Características

- Museo de dos niveles con salas de exhibición.
- Modelos relacionados con la cultura mexicana.
- Objetos construidos mediante primitivas OpenGL.
- Robot guía animado mediante máquina de estados.
- Puertas con apertura y cierre.
- Fuente ornamental y kiosco exterior.
- Jardineras y carretera.
- Automóvil con movimiento de ida y vuelta.

## Controles

| Tecla | Función |
|---|---|
| W, A, S, D | Movimiento de cámara |
| Mouse | Orientación de la cámara |
| P / O | Abrir y cerrar puertas |
| R | Activar animación del robot |
| C | Pausar o reanudar automóvil |
| F | Activar o desactivar fuente |
| 1 al 9 | Cambiar posición de cámara |
| ESC | Salir |

## Ejecución

1. Abrir la carpeta `Ejecutable`.
2. Ejecutar `ConfiguracionInicial.exe`.
3. Mantener las carpetas `Models` y `Shader`
   junto al ejecutable.
