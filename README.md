# Proyecto Final - Computación Gráfica

Este repositorio contiene los archivos correspondientes al proyecto final de la materia de Computación Gráfica.

## Tema

Museo Mexicano

El proyecto consiste en la creación de un museo usando OpenGL, estará compuesta por diferentes modelos relacionados con la cultura mexicana.

## Modelos

Algunos de los modelos incluidos son:

- Taco
- Chiles
- Nopal
- Sombrero
- Caballito de tequila
- Molcajete
- Otros elementos de cultura mexicana
